# Timeline check

1. Find the agreed timeline and supporting documents Wilbur pointed you to for this project. If none, say so and ask Wilbur. Don't guess. The board is the agreed timeline.
2. Read them, then read recent activity: Slack, Jira tickets, open and merged PRs.
3. Compare. Look for:
   - Milestones or tickets that are late or not moving.
   - Work that differs from the documents.
   - Work or requests beyond the documents (scope creep).
   - PRs sitting open with no comments or activity.
   - Risks, such as dependencies, blockers, or unanswered questions.
4. Read the current week's goals only (the latest Monday post) and the Friday recap from the channel. Ignore earlier weeks' goals. Compare them with the board and give an opinion on whether the project is on track, with the reason and how sure you are.
   Flag goals that can't be verified.
5. If you suspect the timeline is off track, write one or two lines on why, with links, plus any context that helps Wilbur decide.
6. If you can't tell, mark it "Unsure" and list the facts.

Read-only. This skill only produces input for the digest or an urgent ping.
