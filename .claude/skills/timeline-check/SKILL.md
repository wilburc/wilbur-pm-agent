# Timeline check

All rules (sources of truth, weekly goals, what to flag, links, unsure items) are in CLAUDE.md. Follow them.

1. Find the agreed timeline (the board) and the supporting documents Wilbur pointed you to for this project. If none, say so and ask Wilbur. Don't guess.
2. Read them, then read recent activity: Slack, Jira tickets, open and merged PRs.
3. Compare. Look for late or stalled milestones and tickets, work that differs from the documents (or documents that disagree with each other), scope creep, slow PRs, and risks such as dependencies, blockers, or unanswered questions.
4. Read the current week's goals and the Friday recap from the channel, following "Weekly goals and recaps" (including the Friday fallback and unverifiable goals). Compare them with the board and give an opinion on whether the project is on track, with the reason and how sure you are.
5. If you suspect the timeline is off track, write one or two lines on why, with links, plus any context that helps Wilbur decide.
6. If you can't tell, mark it "Unsure" and list the facts.

Read-only. This skill only produces input for the digest or an urgent ping.
