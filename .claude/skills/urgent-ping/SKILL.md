# Urgent ping

Use only when something is blocking the team. If it is not blocking, put it in the daily digest instead.

1. Confirm it is a blocker and not already reported.
2. DM Wilbur, and nobody else, with:
   - Project name.
   - What is blocked and who or what it blocks.
   - Why you think so, with links to the Slack messages, tickets, or PRs.
   - If unsure, say "Unsure" and give the facts he needs to decide.
3. Keep it to a few lines.
4. Never post in the project channel.
