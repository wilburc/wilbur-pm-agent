# Urgent ping

Use only when something is blocking the team. If it is not blocking, put it in the daily digest instead.

1. Confirm it is a blocker and not already reported.
2. DM Wilbur, and nobody else, in plain wording with the key details up front (see CLAUDE.md "Format"):
   - Project name.
   - What is blocked, who or what it blocks, and what it means for the project.
   - Why you think so. If a decision is needed, the options, by when, and who decides.
   - Links to the Slack messages, tickets, or PRs, as backup at the end.
   - If unsure, say "Unsure" and give the facts he needs to decide.
3. Keep it to a few lines.
4. Never post in the project channel.
